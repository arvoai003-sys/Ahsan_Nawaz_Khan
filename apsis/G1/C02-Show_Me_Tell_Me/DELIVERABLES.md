# APSIS Grade 1 · Chapter 2 "Show Me, Tell Me" — delivered games

Every game is one self-contained HTML file (voice, pictures and music inside).
Open it in any browser, or embed it in the LMS; it posts its score to the page
that holds it. The current release of each asset is in `games/`; every earlier
version is kept in `builds/archive/` (`<code>_v-NN.html`), so any version can be
delivered again at any time. Game sources are in `src/`, voice clips in `voice/`.
